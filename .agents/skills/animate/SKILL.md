# Анимация СЭС

Только при конкретном поручении на движение прочитай [оригинальный скилл](../../../.claude/skills/animate/SKILL.md); `RECIPES.md` находится рядом с оригиналом. Относительные пути разрешай от исходного каталога.

Сначала соблюдай `AGENTS.md`, `CLAUDE.md` и `DESIGN-SYSTEM.md`: существующие токены движения, CSS и Vanilla TypeScript, без установки Motion, GSAP и других библиотек. Примеры React не переносить в Astro как готовую архитектуру. Правило оригинала об английской приветственной фразе не применяется: отвечай по-русски и выполняй конкретное поручение. При отсутствии задачи на анимацию скилл не активируй.
