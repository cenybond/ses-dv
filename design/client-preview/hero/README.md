# Презентация первого экрана

Отдельная страница для первого показа заказчику: шапка и первый экран (hero) нового сайта «Связь Энергострой». Берётся из прототипа `design/explorations/ses-home-v1/` без изменения композиции, шрифтов (Manrope + Golos Text), палитры и логотипа. Это не Astro-маршрут и не часть DEMO-05.

## Как открыть

Двойной щелчок по `index.html` (`file://`, сервер не нужен). Страница подключает `../../system/` (токены, компоненты, шрифты, логотип) относительными путями, поэтому папку `design/` нужно хранить целиком. Сеть не используется. `styles.css` — копия правил hero из прототипа (без изменений) и блок «Отличия презентации».

## Чем отличается от прототипа

| Убрано | Причина |
|---|---|
| демо-полоса «Демонстрационная версия…» | служебная надпись, мешает первому впечатлению; статус отражён в описании ниже |
| плавающая карточка «Место для фотографии» и рамка-видоискатель | служебные подсказки; вместо них нейтральный фон hero без изображения |
| нижняя панель mobile («Позвонить» / «Оставить заявку») | здесь нет формы; не обещаем заявку |
| диалоги, меню-шторка, якоря | на странице только один экран |

Hero занимает всю высоту окна (`100svh`), содержимое стоит на тех же местах: на desktop по центру, на ширинах ≤ 820 px — внизу, как в прототипе.

## Кнопки

Кнопки «Услуги», «Проекты», «Заказать звонок», пункты меню и бургер в презентации не активны: по нажатию появляется подсказка «Это презентация первого экрана: кнопка пока не активна». Заявка не отправляется, данные не собираются. Номер телефона в шапке (`tel:`) взят со старого сайта, его актуальность заказчиком не подтверждена (Q-29).

## Фон

Фотография не выбрана и не утверждена. Фон — существующий нейтральный фон hero из прототипа (тёмно-зелёный градиент и тонкая сетка), не имитирует фото. Требования к будущему кадру: `design/explorations/ses-home-v1/README.md`, раздел «Замена фотографий».

## Текст для заказчика

> Предлагаем согласовать **визуальное направление первого экрана** нового сайта: расположение логотипа и меню, крупный заголовок «Связь Энергострой», три строки о видах работ, три кнопки действий, тёмно-зелёный фон с фирменным салатовым акцентом, шрифты Manrope и Golos Text. Логотип — оригинальный, из вашего векторного файла. Все тексты перенесены с действующего сайта без изменений.
>
> **Фоновая фотография ещё не выбрана.** Сейчас вместо неё нейтральный тёмно-зелёный фон; кадр подберём из ваших материалов (нужен снимок с объектом в правой части, слева — спокойный фон под текст). Кнопки и меню в этой презентации не работают — это только первый экран, не весь сайт. Контактные данные в шапке взяты со старого сайта и подлежат проверке.
