# Решения

## Approved (из брифа заказчика, 2026-10-12)

| ID | Решение |
|----|---------|
| A-01 | Сайт разрабатывается с нуля. Старая структура и навигация не сохраняются. |
| A-02 | Сохраняются все содержательные разделы, кроме «Благодарности» и «Оснащение». Страницы можно объединять и переносить. |
| A-03 | Тексты переносятся дословно. Нельзя переписывать, сокращать, придумывать факты, проекты, показатели. Можно менять порядок блоков, переносить между секциями, предлагать новые интерфейсные заголовки. |
| A-04 | Из старого дизайна сохраняется только корпоративная палитра. Новые оттенки обозначаются отдельно и согласуются. |
| A-05 | Визуальный ориентир: референс EverMod (композиция и иерархия, без копирования айдентики). |
| A-06 | Фото предоставляет заказчик. До этого только явные заглушки. Замена фото без правки кода компонентов. |
| A-07 | Адрес компании = `ADDRESS_PENDING`. Старый адрес в финальную версию не переносится. Остальные контакты проверяются перед релизом. |
| A-08 | Форма заявки обязательна. Страница политики ПДн обязательна, но текущая политика не считается актуальной до проверки. Способ доставки заявок не выбран, сторонние сервисы не интегрируются самостоятельно. |
| A-09 | Яндекс Метрика будет, но подключается ближе к релизу. ID предоставит заказчик. До этого аналитических скриптов нет. |
| A-10 | CMS, backend, админка не создаются без отдельного решения. |
| A-11 | Для удалённых страниц нужен релевантный 301 или 410. Массовый редирект на главную запрещён. |

## Proposed (требуют согласования)

| ID | Предложение | Обоснование |
|----|-------------|-------------|
| P-01 | Статический сайт (SSG) с контентом в репозитории в виде типизированных файлов (Markdown/JSON), без CMS на MVP. | Корпоративный сайт с редкими правками. Добавить услугу или проект = добавить файл. CMS можно подключить позже к тем же данным. |
| P-02 | Рассмотреть Astro вместо Next.js. Альтернатива: Next.js со `output: 'export'`. | Сайт контентный, интерактива почти нет. Astro отдаёт HTML без JS по умолчанию, это проще и быстрее. Окончательно выбираем после аудита объёма контента. |
| P-03 | Единственный динамический элемент: обработчик формы на сервере в РФ. | Ст. 18 ч. 5 152-ФЗ (локализация ПДн граждан РФ). Зарубежный serverless для формы создаёт юридический риск. Требует проверки юристом. |
| P-04 | Хостинг у российского провайдера. | Следует из P-03 и из аудитории сайта. |
