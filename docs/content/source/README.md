# Снимки исходного контента ses-dv.ru

PHASE 1A. Локальные текстовые снимки существующего сайта https://ses-dv.ru/ (production не изменялся). Дата получения: 2026-10-12. Реестры: [URL-INVENTORY](../../URL-INVENTORY.md), [CONTENT-MAP](../../CONTENT-MAP.md), [SITE-AUDIT](../../SITE-AUDIT.md).

## Состав

- `home.md`, `<путь>.md` — по одному файлу на страницу (42 страницы: 41 из sitemap и `/about`). Имя файла = путь URL (`/` → `home.md`, `/page55167833.html` → `page55167833.md`).
- `_shared.md` — шапка, подвал, попап заявки, cookie-баннер, контакты (общие элементы, чтобы не копировать их в каждый снимок).
- `_image-manifest.csv` — адреса изображений (CDN Tilda) по страницам и блокам. Сами файлы не скачивались и не хранятся.

Алиасы и служебные шаблоны отдельных снимков не имеют (см. CONTENT-MAP).

## Формат снимка

Frontmatter: `source_url`, `fetched_at`, `http_status`, `tilda_page_id`, SEO-поля, `classification` (KEEP / EXCLUDE / REVIEW / EMPTY / DUPLICATE), `content_status` (COMPLETE / CONTENT_INCOMPLETE + причина), `new_url: PENDING`.

Разделы: SEO-метаданные, структура заголовков, текст по блокам Tilda, кнопки, формы, ссылки, изображения, наблюдения.

Текст блоков лежит в блоках ```` ```text ```` дословно, как в HTML (неразрывные пробелы сохранены, пунктуация, регистр и орфография источника не правились). Метки строк: `H1–H6` — семантический заголовок, `TITLE` — заголовок по стилю Tilda, `TEXT` — абзац/строка, `BUTTON` — кнопка Zero-блока.

## Метод и ограничения

- HTML получен GET-запросами, разобран по DOM Tilda (блоки `rec…`). Полнота сверена: каждый текстовый узел основной части присутствует в снимке. Выборочно сверено с отрисованными страницами в браузере (`/advantages`, `/completed-projects`, `/aks`, `/privacy` — совпало точно; `/` — вручную).
- Порядок строк в Zero-блоках (`type 396`) восстановлен по desktop-координатам и приблизителен.
- Тексты внутри изображений (сканы СРО, изображение в «Благодарностях», логотипы заказчиков) не извлекались.
- Старый адрес на `/contacts` сохранён дословно только как источник; в новую версию он не переносится (`ADDRESS_PENDING`).
- Исходные HTML-архивы и фотографии в репозиторий не включаются.
