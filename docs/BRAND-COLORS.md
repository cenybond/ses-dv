## 4. Использование (по измерениям)

- Доминирует `#116315`: навигация, все кнопки, заголовки, подвал, полигоны hero. Остальные тёмные зелёные встречаются точечно.
- Салатовая семья существует только в логотипе, в попапах заявки он выводится на всю ширину окна (см. VISUAL-AUDIT V-12).
- Нейтральная база — белый; серые `#E2E2E2`/`#F2F2F2` только как декор в Zero Block главной.
- Цвета фото и стоковых иллюстраций (синие кнопки, жёлтые каски, цветные иконки) в палитру не входят.
- Акцентного «тёплого» цвета в дизайне нет (оранжевые `#FF8562`/`#FFA600` — случайные цвета ссылок).

## 5. Что неизвестно (требует заказчика)

| Вопрос | Почему важно |
|---|---|
| Есть ли утверждённый бренд-бук, Pantone/CMYK, векторный логотип | Источник для точных значений вместо растрового PNG |
| Какой из зелёных считать корпоративным: тёмный интерфейсный `#116315` и/или салатовые из логотипа | Определяет «корпоративную палитру» для A-04 |

## 7. Исследование принципов цветовых систем (ui-ux-pro-max)

Использованы справочники скилла `ui-ux-pro-max` (поиск `search.py … --domain color` по запросу «construction engineering infrastructure energy B2B contractor» и `references/quick-reference.md`). **Автоматические палитры из базы скилла (например, «B2B Service»: тёмно-синий + синий CTA; «Construction/Architecture»: серо-синий + оранжевый) в проект не приняты** — они противоречат A-04 и не являются измерением. Из справочника взяты только принципы, пригодные для будущей дизайн-системы:
- цвета задаются семантическими токенами (primary, on-primary, surface, border, destructive), а не сырыми HEX в компонентах (`color-semantic`);
- каждая пара «текст/фон» проверяется на 4,5 : 1 (крупный текст — 3 : 1) (`color-contrast`, `color-accessible-pairs`);
- цвет не единственный носитель смысла (`color-not-only`);
- палитра выбирается от продукта и отрасли, но здесь она определяется корпоративной (`color-palette-from-product`).
