# Композиция и адаптивность СЭС

Прочитай [оригинальный скилл](../../../.claude/skills/better-layout/SKILL.md). Связанные справочники открывай рядом с оригиналом, только по необходимости.

Правила `AGENTS.md`, `CLAUDE.md`, токены `design/system/` и согласованный референс имеют приоритет над общими стартовыми размерами. Не меняй тексты и соседние страницы ради компоновки. Проверки длинных строк и RTL выполняй временно в браузере, не переписывая данные продукта. Отсутствующие `better-ui`, `better-writing` и `better-colors` не устанавливай: используй действующие правила проекта. Сообщай на русском о проверенных ширинах и непроверенных сценариях.
