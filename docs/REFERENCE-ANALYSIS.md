# Анализ референса EverMod

Источник: изображение длинной страницы, приложенное к брифу (731×1280 px, уменьшенный скриншот десктопа).
Размеры ниже пересчитаны к ширине макета 1440 px (коэффициент ≈ 1,97) и дают порядок величин, а не точные значения.
Цвета сняты пипеткой с JPEG и приблизительны. Для СЭС они не используются, потому что палитру берём с ses-dv.ru.

## 1. Последовательность секций

| # | Секция | Доля высоты страницы | Что делает |
|---|--------|---------------------|-----------|
| 1 | Hero на полноэкранной фотографии, header поверх фото | ~27% | Обещание + один инструмент действия (подбор по площади) + плавающая карточка конкретного объекта с ценой |
| 2 | Двухколоночный интро-блок: слева кто мы, справа крупный тезис | ~10% | Позиционирование |
| 3 | Полоса из 4 цифр в одной белой карточке с иконками | ~8% | Доказательства масштаба |
| 4 | Заголовок + ссылка на видео + bento-сетка: большое фото / текстовая карточка / фото с ценой и CTA | ~17% | Продукт и путь в каталог |
| 5 | Полоса из 4 преимуществ (иконка, заголовок, 2–3 строки) | ~7% | Аргументы |
| 6 | 3 карточки серий: фото, белая плашка поверх нижней части, круглая кнопка-стрелка | ~9% | Каталог |
| 7 | Форма заявки в светло-зелёной панели: текст слева, 3 поля + кнопка справа, чекбокс согласия | ~9% | Конверсия |
| 8 | Тёмный footer в 4 колонки | ~6% | Навигация, контакты, политика |

Вывод: на главной ровно один экран «мы» (2–3), один экран «продукт» (4–6) и форма в конце. Всё, что дальше от заявки, сжато.

## 2. Композиция и сетка

- Контейнер ≈ 1200 px при ширине 1440, поля ≈ 120 px. Все секции, кроме hero и footer, держат одну линию левого края.
- Скрытая 12-колоночная сетка. Интро: 5 + 7. Bento: 6 + 3 + 3. Цифры и преимущества: 4 × 3. Карточки серий: 3 × 4.
- Вертикальный ритм: между секциями ~60–80 px, внутри карточек ~32–40 px. Расстояния почти одинаковые, поэтому страница читается спокойно.
- Фон страницы почти белый (≈ #F8F8F8), карточки белые с радиусом ~20–24 px и очень мягкой тенью или без неё. Разделение держится на разнице тонов, а не на рамках.

## 3. Hero

- Фото на всю ширину, высота ≈ 690 px (≈ 48% ширины). Затемнение слева, чтобы читался белый текст.
- Заголовок в 4 строки, ≈ 64–70 px, одно ключевое словосочетание выделено акцентным цветом.
- Подзаголовок 2 строки, ≈ 18 px.
- Вместо кнопки стоит поле-селектор с круглой кнопкой поиска. Это сразу переводит в каталог.
- Справа сверху лежит «плавающая» белая карточка конкретного объекта (название, серия, цена).

## 4. Типографика

- Геометрический гротеск с округлыми формами (по облику близко к Gilroy или Manrope). Начертания: Regular для крупных заголовков, Medium/SemiBold для заголовков карточек.
- Крупные заголовки набраны Regular, а не Bold. Это даёт ощущение «дорого и спокойно».
- Иерархия: H1 ≈ 64–70 → H2 ≈ 34–40 → H3 карточки ≈ 20–22 → цифры ≈ 36 → текст ≈ 14–16 → мелкий ≈ 12–13.
- Основной текст серый средней контрастности. На мелком кегле в превью он выглядит бледным, поэтому для нашего сайта контраст обязательно проверить по WCAG.

## 5. Цвет (только для понимания механики)

- Нейтральная база: фон ≈ #F8F8F8, карточки #FFFFFF, footer ≈ #232323.
- Один яркий акцент (лайм ≈ #9EE44A) на CTA, иконках, выделенных словах, кнопках-стрелках. Больше акцентов нет.
- Светлая тонировка акцента (≈ #F7F9F4) работает как фон формы.

Механика, которую стоит перенести: нейтральная база + один корпоративный акцент + его светлая тонировка для зон конверсии.

## 6. Компоненты

| Компонент | Характер |
|-----------|----------|
| Header | Прозрачный поверх hero, логотип слева, 5 пунктов по центру, активный пункт подчёркнут, справа акцентная CTA-кнопка |
| Кнопки | Primary: заливка акцентом, тёмный текст, радиус ~10–12 px, стрелка справа. Secondary: белая с рамкой. Иконочная: круг акцентного цвета со стрелкой |
| Карточка-цифра | Иконка в линейном стиле, число крупно, подпись мелко; 4 в ряд с вертикальными разделителями |
| Карточка с фото | Фото на всю карточку, информационная плашка поверх нижней части, CTA-стрелка в плашке |
| Bento-карточка текста | Иконка, заголовок в 4 строки, абзац, вторичная кнопка внизу |
| Форма | Поля 2 × 2 с кнопкой в сетке, крупные поля с мягким радиусом, чекбокс согласия под формой |
| Footer | Тёмный, 4 колонки: бренд + соцсети, меню, каталог, контакты; копирайт и ссылка на политику внизу |
| Иконки | Тонкие линейные, одного веса, в акцентном цвете |

## 7. Фотографии

- Фото несут всю эмоцию страницы, интерфейс вокруг них нейтральный.
- Один объект в кадре, естественный свет, много неба и окружения.
- Повторяемые пропорции: hero ≈ 2,1 : 1, большое bento ≈ 4 : 3, малое bento ≈ 4 : 3, карточка серии ≈ 16 : 10.
- Референс почти наверняка использует сгенерированные визуализации. Для СЭС это запрещено, поэтому композиция должна работать на реальных фото с объектов (часто менее «глянцевых»).

## 8. Что переносим, а что нет

**Применимо к СЭС:**
- Нейтральная светлая база + один корпоративный акцент.
- Hero на реальном фото объекта с коротким заголовком и одним главным действием.
- Полоса фактов с цифрами. Только если цифры есть на ses-dv.ru, придумывать нельзя.
- Bento-сетка для связки «направление работ → проекты».
- Карточки проектов с плашкой поверх фото и явной стрелкой перехода.
- Единая форма заявки внизу страниц с одним полем-минимумом и согласием.
- Тёмный footer с полной навигацией.
- Регулярная 12-колоночная сетка и одинаковый вертикальный ритм.

**Характерно только для каталога модульных домов, не переносим:**
- Подбор «по площади» в hero. У B2B-подрядчика нет каталога с параметрическим поиском. Аналогом может быть быстрый выбор направления работ, но это гипотеза для фазы IA.
- Цены «от N ₽» на карточках и в hero. Для строительных B2B-услуг цены обычно не публикуются, а выдумывать их запрещено.
- Плавающая карточка «товара» в hero. Её можно заменить карточкой реального проекта (название, заказчик, год), если такие данные есть.
- Пункт меню «Инвесторам» и инвестиционная риторика.
- Эмоциональные тексты для частного покупателя («для жизни и отдыха»).
- Ярко-лаймовый акцент. Цвет берём только из палитры СЭС.

## 9. Риски переноса

- Реальные фото с объектов (опоры, траншеи, подстанции, кабель) сложнее «красивых домиков». Hero с полноэкранным фото требует хотя бы 2–3 сильных кадра. Если их не будет, нужен вариант hero без доминирующей фотографии (рассмотреть в фазе 4).
- Крупный тонкий шрифт плохо переносит длинные русские слова из названий услуг. Типографику проверять на реальных заголовках СЭС, а не на коротких слоганах.
- Бледный серый текст в референсе, скорее всего, не проходит контраст 4,5 : 1.
