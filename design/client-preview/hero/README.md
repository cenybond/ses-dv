# Презентация первого экрана — Hero V4

Финальная визуальная итерация перед показом заказчику, 2026-10-27. Отдельная презентация ООО «Связь Энергострой», не Astro-маршрут. Следующий шаг — показать Hero заказчику; DEMO-05 не начат.

## Открытие

Открыть `index.html` в браузере двойным щелчком. Страница работает по `file://`, без сервера и внешних запросов. Папку `design/` нужно сохранять целиком: CSS, Manrope, Golos Text и SVG подключаются из `../../system/`.

## Что изменено

- Исходный `assets/hero-bg-house.webp` сохранён без изменения байтов. Убрана зелёная маска: на desktop нейтральный градиент из существующего `--color-on-accent` затемняет область текста и шапку, справа фото открыто. Дом и инженерные коммуникации читаются заметнее.
- На ширинах до 1180 px текст и фото разделены. Кадр сохраняет исходные пропорции 1672:941, включая крышу, оборудование и скважину; на mobile ничего не обрезается по бокам. Вверху фото только короткий плавный переход.
- H1 сохранён: «Проектирование и строительство инженерных сетей»; «инженерных сетей» выделено салатовым. Подзаголовок: «Многопрофильная строительно-монтажная организация». Сохранён исходный eyebrow «Осуществляем комплекс работ:».
- Primary «Наши услуги»: pill, высота 56 px, круг стрелки 40 px, одинаковая логика скруглений и равномерный внутренний отступ. Secondary «Проекты»: текстовая кнопка со стрелкой без заливки. «Заказать звонок» в Header тоже pill. На ≤ 960 px сохранена компактная шапка с логотипом и бургером.
- Использован прежний `logo-wordmark-on-dark.svg`; название компании отдельно не повторяется, SVG не изменён.

## Сравнение с EverMod

Оригинал: `design/references/evermod/evermod-home-desktop.webp`. Сравнение визуальное, размеры по скриншоту оценочные; это перенос композиционных принципов, а не точная копия бренда.

| Принцип референса | Решение V4 |
| --- | --- |
| Заголовок слева, выразительная архитектура справа | На 1440 px текст занимает левую часть, правая часть кадра без общей цветовой маски |
| Тонкая линия под «Главная» | В референсе это текущий пункт навигации, не ползунок и не декоративный акцент. Добавлен рабочий якорь «Главная» → `#top` с `aria-current="page"`; неактивные разделы не отмечены текущими |
| Салатовый смысловой акцент и одно главное действие | Акцент в H1 и основная CTA; «Проекты» визуально вторична |
| Воздух между шапкой, заголовком и действием | Общий контейнер, согласованные отступы из токенов; на планшете заголовок и пояснение выровнены сверху |

Цены, сроки, показатели и карточка товара EverMod не переносились. Новые токены и компоненты общей дизайн-системы не создавались. На планшете H1 использует существующий `--type-h1`, на desktop — `--type-display`; сохранено прежнее мобильное ограничение `clamp(31px,10.2vw,46px)`.

Нет горизонтальной прокрутки, выхода текста/контролов за окно, пересечений кнопок, ошибок загрузки и внешних запросов. Размер документа совпадает с окном на всех пяти размерах. Логотип и оба шрифта загружены; цели касания не меньше 44 px. По нажатию CTA появляется прежняя подсказка о презентационном режиме.

Дополнительно на 1440 px сравнили непрозрачные пиксели букв со скриншотом того же фона при скрытом тексте: минимальный контраст белой части H1 — 9,61:1, салатовой — 4,53:1, подзаголовка — 9,97:1. Это адресное измерение данного кадра, не общий аудит доступности. Машинный отчёт — `screenshots/verification-v4.json`. Safari, Firefox, реальные устройства, скринридеры и масштаб 200% отдельно не проверялись.

## Для показа заказчику

Показываем композицию первого экрана, фотографический подход, типографику и приоритет действий. Кнопки разделов и бургер демонстрационные: показывают уведомление, формы не открывают и данные не отправляют. «Главная» возвращает в начало. Телефон взят из прежних материалов; его актуальность ещё не подтверждена.

Фон — временная иллюстрация, не фотография объекта СЭС; соответствующая подпись сохранена на странице. Сохранение кадра и подписи CTA прямо разрешены поручением Hero V4. Это не утверждение кадра для production: согласование фотографий заказчика, финальной компоновки логотипа и остальных открытых вопросов проекта остаётся отдельно.
