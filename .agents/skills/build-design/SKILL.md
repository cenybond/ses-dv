# Перенос дизайна в СЭС

Прочитай [оригинальный скилл](../../../.claude/skills/build-design/SKILL.md); его справочник `figma.md` находится рядом с оригиналом. Остальные относительные пути разрешай от каталога оригинала. Применяй с учётом следующих уточнений Codex:

- Сначала `AGENTS.md`, действующий `CLAUDE.md` и рамки текущего задания. Для Hero референс EverMod задаёт композицию и иерархию; фирменные цвета, логотип и тексты остаются СЭС.
- Локальный WebP — достаточный исходник для задачи по изображению; не требуй Figma, если владелец указал локальный референс. Измерения по изображению обозначай оценочными.
- Используй доступный просмотр локальных изображений и браузерные средства. Для Figma сначала найди доступные инструменты и прочитай соответствующий обязательный скилл установленного Figma-плагина.
- Упомянутые в оригинале родственные скиллы не являются обязательными зависимостями. Выбирай только доступный и нужный для задачи.
- Конфликт референса с доступностью, токенами или дословностью фиксируй; не внедряй заведомо проблемное решение ради совпадения. Не откатывай и не удаляй пользовательские файлы по общей рекомендации оригинала.
