# URL-MIGRATION — предварительная стратегия миграции URL

Фаза PHASE 1C. Дата: 2026-10-13. Статус документа: **Proposed — ожидает согласования заказчика**. Редиректы, коды 404/410, robots.txt и sitemap **в этой фазе не реализуются**: документ описывает намерение для PHASE 2 (SPEC) и разработки.

Основа: полный реестр [URL-INVENTORY.md](URL-INVENTORY.md) (50 URL), новая структура в [INFORMATION-ARCHITECTURE.md](INFORMATION-ARCHITECTURE.md), решения A-02, A-11, A-13…A-16 в [DECISIONS.md](../DECISIONS.md).

## 1. Правила

1. **Массовых редиректов на главную нет** (A-11). Главная — цель только у самой главной.
2. **301 ставится только при наличии релевантной цели.** Цепочек нет: старый адрес ведёт сразу на конечный.
3. **Исключённое содержание** (`/mtb`, `/gratitude`) — 410 Gone: решение принято заказчиком, замены нет. Служебные шаблоны — 404.
4. **Пока вопрос открыт, статус REVIEW** (`/sro-p`, `/sro-s`, `/page55167833.html`, `/news`) — предварительный вариант указан, но не назначается.
5. **Смысл адресов сохраняется**: ключевые слова слагов проектов совпадают со старыми (`/tlt` → `/projects/tlt`), числовые `/1`…`/12` получают смысловые слаги.
6. **Страницы с полезной информацией не удаляются**: удаляются только исключённые заказчиком и служебные.
7. **Риски оценены по структуре, а не по трафику**: данных Метрики, Вебмастера и логов нет. Фактическая индексация не проверялась.
8. Редиректы 301 сохраняются не менее года (рекомендация поисковых систем; срок подтвердить в SPEC).

## 5. Технические требования к SEO-слою нового сайта

Реализуются в SPEC и разработке; здесь — только требования из аудита 1A.

| Тема | Требование | Основание |
|---|---|---|
| Canonical | У каждой публичной страницы — self-canonical на единственный адрес | Сейчас canonical верен, но есть дубли с регистром, слэшем и `www` |
| Один вариант адреса | Выбрать форму (с завершающим слэшем или без) и 301 с другой; рекомендуется без слэша, как сейчас в canonical; решение зависит от выбранного хостинга (SPEC) | `/services/` и `/Services` сейчас отдают 200 |
| `www` | 301 `www.ses-dv.ru` → основной хост | Сейчас 200 без редиректа |
| Регистр | Нормализация к нижнему регистру (301) | `/SERVICES` → 200 |
| `http` → `https` | Сохранить 301 | Работает |
| Код 404 | Любой несуществующий адрес отвечает **404**, не 200; страница 404 с навигацией | `/error` и `/page36950621.html` отдают 200 (мягкая 404) |
| 410 | Нужна поддержка на уровне сервера; если хостинг не позволяет — 404 и страница 404 с навигацией (вынести в SPEC) | `/mtb`, `/gratitude` |
| robots.txt | Новый файл: убрать `Disallow` для `/about`; не переносить правила `/tilda/*` и служебных страниц Tilda; не ссылаться на `sitemap-feeds.xml` | Сейчас `Disallow: /about`; `sitemap-feeds.xml` → 404 |

| Метаданные | title, description, og: — новый текст (SPEC), не копировать дефектные: `#nbsp;` в title, «Прокол для водопровода» на `/contacts`, «Blank page», «СРО П»; факты не придумывать | [SITE-AUDIT.md](SITE-AUDIT.md) §8 |
