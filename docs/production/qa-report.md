## Performance

Наблюдения на локальном HTTP без CPU/network throttling: при 390 px LCP 360 мс, CLS 0; при 1440 px LCP 300 мс, CLS 0,00065. Страница передала около 651 КБ, 13 ресурсов. Это короткие замеры до взаимодействия, не Lighthouse, не мобильная сеть и не полевые Core Web Vitals. Они сделаны до последней перестановки карточек ниже первого экрана; повторно измерить на реальном staging после добавления фотографий.

Шрифты и Hero локальные; отсутствуют сторонние виджеты, карты и активная аналитика. Метрика, будущие фотографии и hosting изменят профиль загрузки. Перед выпуском нужны Lighthouse/полевые проверки на выбранной инфраструктуре и оптимизация реальных изображений.

## Security summary

Default API возвращает 503 до чтения тела. Live transport отсутствует; положительные тесты используют синтетические данные и тестовый transport. Только подтверждение транспорта даёт успех. Есть ограничения метода/типа/размера тела, точного Origin, контекстов, частоты, TTL/объёма памяти и повторов; payload/IP не пишутся в журналы приложения. Реальный provider idempotency, reverse proxy, TLS, секреты, retention и распределённый rate limit зависят от размещения и требуют проверки до активации.

Staging обслуживает только dist, применяет CSP с hash без unsafe-inline/unsafe-eval, noindex и защитные headers; секреты и server не попадают в static output. Метрика не загружается, внешних сетевых запросов в браузерных тестах нет. Подробности и ограничения — [security.md](security.md). Внешний pentest и онлайн vulnerability audit не проводились.
