# PLAN-DEMO — план реализации демо

PHASE 2, дата 2026-10-13. Статус: **Proposed**. Реализация не начата. Спецификация — [SPEC-DEMO.md](SPEC-DEMO.md), стек — [ARCHITECTURE-DEMO.md](ARCHITECTURE-DEMO.md), визуальные рамки — [DESIGN-BRIEF.md](DESIGN-BRIEF.md).

Нумерация: **PHASE n** — общие фазы проекта (PHASE 3 — визуальные концепции, PHASE 4 — дизайн-система), **DEMO-nn** — шаги реализации демо. Первоначальная последовательность из задания пересмотрена по результатам аудита (§2): шаг «форма» перенесён раньше страниц, добавлен шаг данных и проверки дословности, «О компании» и «Контакты» разделены, добавлены «Политика и 404» и сквозные проверки.

## 0. Общие правила для всех шагов

| Правило | Содержание |
|---|---|
| Размер шага | одна цель, один коммит; шаг не начинается, пока предыдущий не принят |
| Базовая проверка (с DEMO-02) | `npm run verify` = `astro check` + `eslint` + `prettier --check` + `astro build` + проверочные скрипты, существующие к этому шагу: `check-tokens` (с DEMO-02), `check-copy` (с DEMO-03), `check-links` (с DEMO-04). Состав `verify` расширяется в шаге, который создаёт скрипт |
| Визуальная проверка | встроенный браузер: сборка через `npm run preview`, ширины 1440 × 900 и 390 × 844, скриншоты просматриваются, консоль без ошибок; каждая страница — в обоих размерах в шаге, где она создана |
| Откат | коммит шага откатывается `git revert <hash>`; `reset --hard` не используется; перед шагом — чистое `git status` |
| Запреты на всех шагах | production `ses-dv.ru` не трогать; новых текстов вне S/U/M нет; фото со старого сайта и сток не добавлять; аналитики, внешних запросов, backend нет |
| Фиксация | результат шага и проверок — в `PROGRESS.md`; при изменении порядка — запись в `DECISIONS.md` |
| Ветка | разработка идёт не в `main`; ветка реализации выбирается перед DEMO-02 (рекомендация — отдельная `demo/frontend` от `integration/docs-and-skills`) |

## 1. Последовательность

```text
PHASE 3 визуальные концепции → ГЕЙТ G1 (заказчик выбирает направление)
  → PHASE 4 / DEMO-01 дизайн-система → DEMO-02 foundation → DEMO-03 данные и тексты
  → DEMO-04 layout и навигация → DEMO-05 диалог и демо-форма
  → DEMO-06 главная → DEMO-07 услуги → DEMO-08 проекты → DEMO-09 ТЛТ
  → DEMO-10 о компании → DEMO-11 контакты → DEMO-12 политика и 404
  → DEMO-13 сквозные проверки → DEMO-14 визуальный аудит → DEMO-15 подготовка презентации
```

Гейты: **G1** после PHASE 3 (направление), **G2** перед DEMO-02 (подтверждение стека и разрешение на установку зависимостей и браузера Playwright), **G3** после DEMO-15 (показ заказчику; решения по Q-xx).
