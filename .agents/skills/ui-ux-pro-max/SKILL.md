# Дополнительная UI/UX-проверка СЭС

Прочитай [оригинальный скилл](../../../.claude/skills/ui-ux-pro-max/SKILL.md); справочники, Python-скрипты и CSV остаются в этом исходном каталоге. Относительные ссылки разрешай от него. Следующие уточнения имеют приоритет:

- `CLAUDE_PLUGIN_ROOT` в Codex не требуется. Во всех командах оригинала замени `${CLAUDE_PLUGIN_ROOT}/.claude/skills/ui-ux-pro-max/scripts/search.py` абсолютным путём от корня текущего репозитория к `.claude/skills/ui-ux-pro-max/scripts/search.py`.
- Пример из корня репозитория в PowerShell:

```powershell
$repo_root = (Get-Location).Path
python -B (Join-Path $repo_root '.claude/skills/ui-ux-pro-max/scripts/search.py') 'heading wrap balance' --domain ux -n 1
```

- Python 3 и стандартная библиотека достаточны; ничего не устанавливай. `-B` предотвращает появление `__pycache__` в исходных скиллах.
- Для существующего СЭС используй одну конкретную область `--domain` либо `--stack astro`; проверяй релевантность результатов. Не запускай `--design-system`, `--persist`, `--force` и создание `MASTER.md` для C0 или Hero V4.
- Утверждённые цвета, шрифты, тексты, токены и референс проекта важнее рекомендаций каталога. Каталог не даёт разрешения подключать GSAP, React, шрифты, библиотеки и новые иконки.
