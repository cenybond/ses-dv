# Прототип главной СЭС — v1

Один HTML/CSS-прототип главной страницы (PHASE 3; в PHASE 4 подключены общие токены и компоненты `design/system/`, вставлен оригинальный логотип). Это **не** Astro-проект. Правила — [DESIGN-SYSTEM.md](../../../DESIGN-SYSTEM.md). Описание решений — [docs/DEMO-VISUAL-DIRECTION.md](../../../docs/DEMO-VISUAL-DIRECTION.md).

## Как открыть

Двойной щелчок по `index.html` (протокол `file://`, сервер не нужен). Сеть не используется: шрифты, стили, логотип и скрипт лежат в репозитории (`../../system/`).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | разметка главной: header, hero, о компании, 3 преимущества, 10 услуг, 6 проектов, обращение (форма), footer, диалоги |
| `styles.css` | только то, что специфично главной (hero, плавающая карточка, интро). Токены и компоненты вынесены в `../../system/` (PHASE 4) |
| `../../system/tokens.css`, `system.css`, `system.js` | токены, базовые стили и компоненты, поведение (шапка, меню, диалоги, демо-форма); общие для прототипа и style guide |
| `../../system/logo/` | оригинальный логотип заказчика в SVG (header, footer, favicon) |
| `../../system/fonts/` | Manrope и Golos Text, WOFF2 (кириллица + латиница), лицензии OFL-1.1 (≈ 99 КБ) |
| `screenshots/` | скриншоты 1440 / 768 / 390 px, диалоги; обновлены в PHASE 4 (новый логотип). `compare-reference-vs-prototype.png` — из PHASE 3, со старым временным знаком |

## Что работает

- Якоря шапки и меню: «Услуги», «Проекты», «О компании», «Контакты».
- Мобильное меню (до 960 px): открытие, закрытие кнопкой, Esc и по фону, фокус возвращается на кнопку.
- Нижняя панель на mobile (до 640 px): «Позвонить» (`tel:`) и «Оставить заявку».
- Диалог заявки: открывается из «Заказать звонок», из карточки услуги (в окне показана услуга) и из нижней панели.
- Форма (диалог и блок обращения): клиентская проверка, сообщение «Это демонстрация. Заявка не отправлена, введённые данные не сохранены». Нет `action`, нет `name` у полей, нет сетевых запросов, нет `localStorage`/cookie.
- `tel:`, `mailto:`, WhatsApp — рабочие ссылки на контакты из старого сайта (актуальность не подтверждена, Q-29).

## Что намеренно не работает

Страниц `/services`, `/projects`, `/projects/tlt`, `/about`, `/privacy` в прототипе нет. Элементы, которые вели бы на них («Все услуги», «Все проекты», «Подробнее о компании», стрелка у проекта ТЛТ, «Политикой конфиденциальности»), открывают окно «Демонстрационное ограничение» с названием будущей страницы. Остальные пять карточек проектов и «Вакансии» в footer — не ссылки, с пометкой «В полной версии».

## Замена фотографий

Фото сейчас нет, везде явные заглушки «Место для фотографии». Пока в разметке только заглушки; при замене слот меняется на `<img>` с `object-fit: cover`, макет не меняется.

| Слот | Пропорция | Рекомендуемый размер | Минимум | Примечание |
|---|---|---|---|---|
| Hero (`.hero__photo`) | 21 : 9 (на mobile обрезается по центру до ≈ 4 : 5) | 2880 × 1235 px | 1920 × 823 px | Объект в правой половине кадра, слева — спокойный фон под текст; затемнение `.hero__shade` слева обязательно, чтобы текст держал контраст ≥ 4,5 : 1 |
| Карточка проекта (`.slot`) | 16 : 10 | 1600 × 1000 px | 1200 × 750 px | Главный объект в верхних 60 % кадра: нижние ≈ 64 px перекрывает белая плашка. Вертикальные кадры обрезаются по центру |

Формат — WebP или JPG, hero ≤ 300 КБ, карточка ≤ 150 КБ. `alt` задаёт заказчик/редактор; у заглушек `alt` пустой.
