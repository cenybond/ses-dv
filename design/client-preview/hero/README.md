# Презентация первого экрана (V2, вариант A)

Отдельная страница для показа заказчику: шапка и первый экран (hero) нового сайта «Связь Энергострой». Визуальное направление — **вариант A, акцент на деятельности компании**. Основа — прототип `design/explorations/ses-home-v1/`; шрифты Manrope + Golos Text, палитра и логотип из `design/system/`. Это не Astro-маршрут и не часть DEMO-05.

## Как открыть

Двойной щелчок по `index.html` (`file://`, сервер не нужен). Страница подключает `../../system/` (токены, компоненты, шрифты, логотип) относительными путями, поэтому папку `design/` нужно хранить целиком. Сеть не используется. `styles.css` — только локальные правила презентации (hero, шапка в три колонки, затемнение).

## Композиция

| Элемент | Содержание |
|---|---|
| Шапка | слева логотип; по центру «Услуги», «Проекты», «О компании», «Контакты»; справа телефон и салатовая «Заказать звонок». На ≤ 960 px — логотип и бургер |

| Подзаголовок | «Многопрофильная строительно-монтажная организация» |
| CTA | **Primary** — «Наши услуги» (салатовая заливка, стрелка в круге). **Secondary** — «Смотреть проекты» (текстовая ссылка со стрелкой) |

Тексты eyebrow, H1 и подзаголовка — дословно из `docs/content/source/home.md` (блок `rec651850071`). Подписи кнопок «Наши услуги» и «Смотреть проекты» в исходных материалах отсутствуют: заданы владельцем проекта в этом задании (подписи интерфейса, не текст источника). Третья строка старого hero («Строительство промышленных, гражданских зданий и других сооружений») в презентацию не вошла, в данных она сохранена. «Заказать звонок» в hero нет — только в шапке.

H1 использует токен `--type-display` (до 76 px). На ≤ 640 px размер ограничен `clamp(31px, 10.2vw, 46px)`, чтобы слово «Проектирование» не выходило за поле на 320 px; других отступлений от типографической шкалы нет.

## Логотип

Шапка использует `design/system/logo/logo-wordmark-on-dark.svg` — официальное название «Связь Энергострой» из `brand/source/logotip-vektor.pdf`, белое на тёмном (200 px, на ≤ 640 px — 168 px). Название в hero не повторяется. **Это временное размещение.** Полный знак (`logo-full-on-dark.svg`, знак над названием) в шапке высотой 72–84 px нечитаем (название ≈ 10 px), а горизонтальная перекомпоновка знака и названия не создавалась (Q-34). Окончательная горизонтальная компоновка ждёт отдельного утверждения.

## Фон

`assets/hero-bg-house.webp` (1672 × 941, 401 КБ) — переданное владельцем проекта изображение дома в разрезе с инженерными коммуникациями. **Временный рабочий кадр для показа, не фотография объекта СЭС и не утверждённый материал**; на странице подписан «Временный кадр: иллюстрация, не объект СЭС». Изображение не менялось, не растягивается (`cover`), внешних запросов нет.

- **Desktop (> 820 px).** Кадр занимает правую часть hero (левый край растворяется маской), дом справа от текста. Затемнение — градиент слева направо, чёрно-зелёный (`8,18,12`): ≈ 88 % у левого края, ≈ 60 % на середине экрана, ≈ 30 % правее центра, ≈ 8–12 % справа; сверху градиент под шапку, снизу лёгкая виньетка. На ≤ 1180 px затемнение держится дальше вправо (текст шире относительно экрана). У eyebrow, H1 и подзаголовка мягкая тень текста.
- **Mobile и планшет (≤ 820 px).** Текст сверху на тёмном фоне, кадр полосой снизу (высота `clamp(300px, 56vw, 460px)`), верх полосы плавно уходит в фон, поверх полосы затемнение около 30–60 %. Текст не попадает на пёстрый участок.
- Сетка из прототипа убрана: кадр заменил её.

## Кнопки

Пункты меню, «Заказать звонок», «Наши услуги», «Смотреть проекты» и бургер не активны: по нажатию появляется подсказка «Это презентация первого экрана: кнопка пока не активна». Заявка не отправляется, данные не собираются, аналитики и backend нет. Телефон в шапке (`tel:`) взят со старого сайта, актуальность заказчиком не подтверждена (Q-29).

## Открытые вопросы

1. Фоновый кадр — иллюстрация, не объект СЭС; решения A-06 и A-25 («только заглушки, фото даёт заказчик») для показа нужно явно переопределить в `DECISIONS.md`.

3. Подписи «Наши услуги» и «Смотреть проекты» — согласовать как подписи интерфейса.
4. Третья строка старого hero в презентацию не вошла — согласовать, нужна ли она где-то на главной.
